🔍 JSONPath Reference

JSONPath is a query language for JSON, similar to XPath for XML.

Basic Syntax

$ Root object/element
@ Current object/element
.property Selects the property
['property'] Selects the property (bracket notation)
[n] Array index
[0, n] Union of indices
[start:end] Array slice
[*] All array elements
[?(expression)] Filter expression
..property Recursive descent

Filter Operators

  • ==, !=, <, >, <=, >= - Comparison
  • =~ - Regular expression match
  • in - Check if value is in array
  • contains - Check if string contains substring
  • size - Array/string length
  • !expression - Negation

Examples

  • $.store.book[*].author - All book authors
  • $..author - All authors anywhere
  • $.store.book[0] - First book
  • $.store.book[-1:] - Last book
  • $.store.book[?(@.price < 10)] - Books under $10
  • $.store.book[?(@.category == 'fiction')] - Fiction books
